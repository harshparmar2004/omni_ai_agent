# Cherry (@cherry_official) Asset Directory

This directory stores facial and full-body reference image anchors for **Cherry**, our flagship photorealistic AI Influencer.

## Recommended Reference Files:
- `face_front.png` — Clear, well-lit front-facing portrait (1024x1024 or higher).
- `face_angle.png` — Three-quarter angled portrait for dynamic turning poses.
- `body_full.png` — Full-length standing shot showing natural physique and proportions.

## Wan 3.0 Real-World Passthrough:
When input video reels are dispatched to the official Alibaba Wan 3.0 API via DashScope, these reference images ensure facial fidelity, consistent skin tone, and persona persistence across all generated reels.
